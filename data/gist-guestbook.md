# mrhakan 98 — guestbook

**this gist is a guestbook. the comments below are the entries.**

sign it from the site — <https://mrhakan.github.io> → guestbook.exe →
_sign it!_ — and it writes the comment for you and copies it. or just
comment here by hand:

```
name: your name
site: https://your.site

whatever you want to say
```

both header lines are optional. no name, no problem — your github
account is the name then. the site puts your github login next to
whatever name you type either way.

nothing here gets committed to my repo, nobody has to fork anything, and
i moderate by deleting comments. that is the whole system.

best viewed at 800x600.
