THE RULES

Fill each row and column with 1, 2, 3, 4, once each. Every < or > must be true. For vertical signs, ∨ means the top number is larger, and ∧ means the bottom is larger.

Select a square, then choose a number.

Blue squares are fixed. Red means a row, column or sign is violated. Arrow keys move selection; 1–4 enter a number; Delete clears; U undoes, H hints, R restarts. Each UTC day has a deterministic puzzle checked for exactly one solution. No network requests; clean best time stays on this device.
