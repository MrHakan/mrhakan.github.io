How to play

  1. Place light bulbs on white squares. Each bulb lights its row and column until a wall.
  2. Every white square must be illuminated. Two bulbs must never see each other.
  3. A numbered wall requires exactly that many bulbs directly beside it.
  4. Tap a square to cycle empty → bulb → X → empty. X is only a note.

Right-click to mark X. Use arrows to navigate, B for bulb, X for note and U to undo. Eight independently verified single-solution boards. Daily rotation uses UTC. Progress and clean best times stay on this device.
