Vault manual

Break the four-digit code in eight guesses.
  • Each digit is between 1 and 6; none repeats.
  • Green pegs: right digit, right position.
  • Gold pegs: right digit, wrong position.
  • Pegs show counts, not which digits matched.
  • Daily vault is identical for everyone on the same UTC date.

Use the keypad or keyboard 1–6. Backspace removes the last digit; Enter submits. The optional hint reveals one exact position and marks the round assisted. Daily and practice rounds never contact a server.
