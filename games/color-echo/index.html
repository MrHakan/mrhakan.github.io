How to play

Watch the flashing pads. Repeat the exact sequence by tapping the pads or pressing 1, 2, 3, 4. Each round adds one light. A wrong answer ends your run. Daily mode uses the same sequence for everyone on the same UTC date.

The sequence is deterministic for daily challenges, but practice is randomly generated. Your best round is stored only in this browser.

Sound is optional and only starts after a user action. Animations are shortened when reduced motion is preferred.
