Quick guide

First row = column names. Choose a text column for the horizontal axis and a numeric column for values. Empty or invalid numeric rows are skipped, not interpreted as zero.

Up to 80 plotted rows and 12 columns. Exported SVG includes a title and description for screen readers. Use the data table below the chart to inspect exact values.

The editor is entirely client-side: no account, network request, tracking, API key, or third-party script.
